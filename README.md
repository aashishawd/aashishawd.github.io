## 🚀 Hosting on GitHub Pages

### Option A — User site (recommended)
1. Create a repository named **`aashishawd.github.io`** (must match your GitHub username).  
2. Upload `index.html` and `Aashish Awadhani.pdf` to the root of the repo.  
3. Commit the changes.  
4. Your site will be live at **https://aashishawd.github.io** within 1–2 minutes.

### Option B — Project site
1. Create a repo with any name (e.g., `portfolio`).  
2. Upload the files to the root.  
3. Go to **Settings → Pages** → Set **Source: Deploy from branch → main → /(root)** → Save.  
4. Your site will be live at **https://aashishawd.github.io/portfolio**.

## ✏️ Editing Content
- Open `index.html` in the repo → click the **pencil icon** to edit.  
- Update text (About, Experience, Projects, Skills, etc.) as needed.  
- Commit changes → refresh site to see updates.  

> ⚠️ Make sure the file is named exactly `index.html` (case-sensitive).
